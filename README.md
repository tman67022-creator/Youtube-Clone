# Youtube Clone

A frontend project that recreates the YouTube video streaming platform.

## 🔗 Live Site

**[Visit the live Youtube Clone](https://tman67022-creator.github.io/Youtube-Clone/)**

## 🔗 Clone This Project

```bash
git clone https://github.com/tman67022-creator/Youtube-Clone.git
```

## About

This is a clone of YouTube - a video sharing and streaming platform. It's built using basic web technologies to demonstrate how video platforms work and how to create interactive user interfaces.

## Features

- Browse videos in a grid layout
- Search for videos
- View video details with thumbnails
- Play video functionality
- Responsive design for mobile and desktop
- Clean and intuitive user interface
- Video recommendations

## Tech Used

- HTML
- CSS
- JavaScript

## How to Run

1. **Clone the repository** (see link above)

2. **Open `index.html` in your browser**

OR use a local server:
```bash
python -m http.server 8000
```

Then go to `http://localhost:8000`
